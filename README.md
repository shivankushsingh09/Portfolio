# Portfolio Website - Shivankush Singh

This is a personal portfolio website developed for Shivankush Singh, an M.Tech CSE (AI&ML) student.
The website showcases his About, Education, Skills, and Projects.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome

## Project Structure
- `index.html`: Home page/Landing page.
- `about.html`: Biography and About Me.
- `education.html`: Educational background timeline.
- `skills.html`: Technical skills exposure.
- `projects.html`: Showcase of projects.
- `contact.html`: Contact form and details.
- `assets/`: Contains CSS, JS, and Images.

## How to Run
1. Clone the repository.
2. Open `index.html` in any modern web browser.
